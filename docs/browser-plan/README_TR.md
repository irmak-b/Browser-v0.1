# BrowserPlan — proje belgeleri

BrowserPlan V1.0.1.0, Electron Browser Core için A1–A5 geliştirme kapsamını tanımlar. Uygulama sürümü ayrı olarak V1.0.14.0'dır.

## Teknik yön

- Electron + React + TypeScript.
- Chromium için ayrı WebContentsView.
- Nihai arayüz için Tailwind.
- Veri katmanı için Neon PostgreSQL ve yetkili API.
- Persona için yalnız tema/maskot sunumu.
